# 리뷰 코멘트 작성 가이드

모든 코멘트의 `body`는 반드시 아래 가이드를 따라 작성합니다.
리뷰 텍스트 코멘트는 반드시 [P(n)룰](#pn룰)을 적용하여 아래 예시에 맞게 작성합니다.

```text
[🙇‍♂️ AI 리뷰]
P{우선순위}) {코멘트 내용}
```

예시:
- `[🙇‍♂️ AI 리뷰]\np1) 해당 변경은 치명적인 오류를 유발할 수 있습니다. 반드시 수정 부탁드려요.`

# P(n)룰

모든 리뷰 코멘트는 반드시 아래 우선순위 태그 중 하나를 접두사로 포함해야 합니다.

## p1: 꼭 반영해주세요 (REQUEST_CHANGES)
PR 내용이 서비스에 중대한 오류를 발생할 가능성이 있거나, 중대한 코드 수정이 반드시 필요한 경우 사용합니다.

## p2: 적극적으로 고려해주세요 (REQUEST_CHANGES)
수용을 권장하며, 수용할 수 없다면 적합한 의견으로 토론해야 합니다.

## p3: 웬만하면 반영해 주세요 (COMMENT)
수용하거나, 수용할 수 없다면 반영할 수 없는 이유를 설명해야 합니다.

## p4: 반영해도 좋고 넘어가도 좋습니다 (COMMENT)
무시해도 괜찮지만 고민해보는 정도면 충분합니다.

## p5: 그냥 사소한 의견입니다 (COMMENT)
단순 사소한 의견입니다.
